## 4.6 The Forty-Five-Minute Matrix Build Sprint

### 4.6.1 Sprint Session Prep Checklist

- [ ] Chapter 3 psychological profile open beside you (the seven-layer excavation document)
- [ ] Blank document open and ready for the matrix
- [ ] AI tool open (needed for Steps 2 and 3)
- [ ] Layer-to-Field Mapping Reference visible (section 4.2.1)
- [ ] Timer set for forty-five minutes
- [ ] Permission granted: this draft does not need to be perfect

### 4.6.2 Forty-Five-Minute Pacing Guide

| Time Block | Step | Focus |
|---|---|---|
| 0:00–15:00 | Step 1 | Populate all six fields from your profile |
| 15:00–25:00 | Step 2 | Generate and verify three stress-test scenes |
| 25:00–38:00 | Step 3 | Iterate failing fields (up to three cycles) |
| 38:00–42:00 | Step 4 | Save, label, and archive |
| 42:00–45:00 | Buffer | Read the matrix aloud. Confirm the voice activates. |

**Step 1 Detail:** Work through each of the six fields in order. Write two to four constraint statements per field in imperative language. Use the Field Population Quick Reference below to confirm you are pulling from the correct layers.

**Field Population Quick Reference:**

| Field | Pull From | Write As |
|---|---|---|
| Cadence Signature | Layers 1 + 2 | Rhythmic pattern + historical reason |
| Vocabulary Ceiling | Layers 1 + 3 | Word range + defensive shift |
| Sentence Architecture | Layers 1 + 4 | Structure baseline + pressure variation |
| Emotional Default | Layers 5 + 6 | Temperature + leakage rate |
| Conversational Rhythm | Layers 4 + 3 | Entry / sustain / exit behavior |
| Signature Tics | All layers | 2–3 idiosyncratic verbal fingerprints |

**Step 2 Detail:** Use the three AI prompt templates in section 4.4.2. Log results in the verification log.

**Step 3 Detail:** Follow the Refinement Loop Protocol in section 4.5.1. Log each cycle in the Iteration Tracker.

**Step 4 Detail:** Save, label, and archive using the protocol below.

### 4.6.3 Matrix Save and Deploy Protocol

- [ ] File name follows this format: **[CHARACTER_NAME] — Dialogue Matrix — v1.0 — [DATE]**
- [ ] File is stored alongside the Chapter 3 psychological profile in your project directory
- [ ] You can locate and open the file in under ten seconds
- [ ] You have read the matrix aloud one final time and heard the character's voice
- [ ] You have resisted the urge to make one more adjustment after passing the stress test
