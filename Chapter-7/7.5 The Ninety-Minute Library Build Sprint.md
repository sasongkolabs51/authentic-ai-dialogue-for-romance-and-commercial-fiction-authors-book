## 7.5 The Ninety-Minute Library Build Sprint

### 7.5.1 Sprint Session Prep Checklist

- [ ] All Dialogue Matrix files from Chapter 4 located and accessible
- [ ] All Three-Tier Emotional Filter files from Chapter 5 located and accessible
- [ ] All genre-calibration settings from Chapter 6 located and accessible
- [ ] Document-management tool open (Scrivener, Notion, or file system)
- [ ] Naming convention reference visible: "[CHARACTER_NAME] — [ASSET_TYPE] — [ARC_STAGE] — [EMOTIONAL_STATE] — [SCENE_TYPE] — v[VERSION_NUMBER] — [DATE]"
- [ ] Timer set for ninety minutes
- [ ] Current work-in-progress open (needed for Step 3 tests)

### 7.5.2 Ninety-Minute Pacing Guide

| Time Block | Step | Focus |
|---|---|---|
| 0:00–20:00 | Step 1 | Create the folder structure |
| 20:00–50:00 | Step 2 | Migrate Dialogue Matrices and Emotional Filters |
| 50:00–75:00 | Step 3 | Run three timed Pull-and-Deploy tests |
| 75:00–90:00 | Step 4 | Establish the version-control protocol |

### 7.5.3 Step 1: Folder Structure Verification Checklist

Complete during minutes 0–20. Confirm before moving to Step 2.

- [ ] Top-level "Character Voice Library" folder created
- [ ] Series subfolder created and labeled
- [ ] Character subfolder created for [CHARACTER_A_NAME]
- [ ] Character subfolder created for [CHARACTER_B_NAME]
- [ ] Arc-stage subfolders created within each character folder
- [ ] All folders labeled using the naming convention
- [ ] Navigation path from top-level to any file is no more than four clicks deep

### 7.5.6 Step 4: Version-Control Verification Checklist

Complete during minutes 75–90.

- [ ] Every active file displays the correct version number in its file name
- [ ] "Archive" subfolder created within each character directory
- [ ] All duplicate or outdated versions moved to the archive
- [ ] Each active file contains a one-line note: last substantive change date and description
- [ ] I can look at any file and immediately identify whether it is the current version
- [ ] I can open the archive and locate any previous version in under fifteen seconds
