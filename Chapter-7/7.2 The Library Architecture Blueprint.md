## 7.2 The Library Architecture Blueprint

### 7.2.1 The Five Organizational Tags

The library uses five tags to build a path for finding information. That path is made up of five questions and their five answers, all kept together in one file.

| Tag | What It Identifies | Example |
|---|---|---|
| **Series** | Which book or series the asset belongs to | "The Ashford Series" or "Standalone: Winter Hearts" |
| **Character** | Which character the asset belongs to | "Callum" or "Mara" |
| **Arc Stage** | Where the character is in their emotional journey | "Book 1 — Maximally Guarded" or "Book 4 — Defenses Cracking" |
| **Emotional State** | The specific emotional configuration the asset governs | "Baseline Guarded" / "Vulnerability" / "Conflict" |
| **Scene Type** | Which of the eight scene types the asset is calibrated for | "Dark Moment" / "First Kiss" / "Banter-Heavy Montage" |

### 7.2.2 Folder Structure Template

Create this structure in your document-management tool (Scrivener research folder, Notion database, or file system).

```text
Character Voice Library/
└── [SERIES_NAME]/
    └── [CHARACTER_NAME]/
        ├── [ARC_STAGE_1]/
        │   ├── [CHARACTER_NAME] — Dialogue Matrix — [ARC_STAGE] — [EMOTIONAL_STATE] — [SCENE_TYPE] — v1.0 — [DATE]
        │   ├── [CHARACTER_NAME] — Three-Tier Emotional Filter — [ARC_STAGE] — [EMOTIONAL_STATE] — [SCENE_TYPE] — v1.0 — [DATE]
        │   └── [CHARACTER_NAME] — Genre Calibration Settings — [ARC_STAGE] — [EMOTIONAL_STATE] — [SCENE_TYPE] — v1.0 — [DATE]
        ├── [ARC_STAGE_2]/
        │   ├── [Same three asset types, updated versions]
        │   └── ...
        └── Archive/
            └── [All previous versions, retaining original names]
```

**Structure rules:**
- The path from the top-level folder to any file must take no more than four clicks.
- Each character gets their own folder that contains every version of every asset.
- The active folder holds only the most current version of each asset.
- The Archive subfolder keeps all previous versions, and you organize and retain every version.

### 7.2.3 Naming Convention Reference

Every file in the library follows this format:

**"[CHARACTER_NAME] — [ASSET_TYPE] — [ARC_STAGE] — [EMOTIONAL_STATE] — [SCENE_TYPE] — v[VERSION_NUMBER] — [DATE]"**

**Example:** *"Callum — Dialogue Matrix — Book 3 — Baseline Guarded — All Scenes — v2.1 — 2025-01-15"*

This convention makes every asset identifiable, sortable, and retrievable without opening the document. You can scan the folder and know exactly what each file contains before you click.
