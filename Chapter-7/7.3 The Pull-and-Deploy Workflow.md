## 7.3 The Pull-and-Deploy Workflow

The Pull-and-Deploy workflow is your daily retrieval process. Execute these four steps before every generation pass. The consistency of the process is what makes sixty-second speed possible.

### 7.3.1 Scene Parameter Identification Worksheet

Finish this setup before you open your library. It takes about thirty seconds and covers four parameters.

**Date:** [DATE]
**Writing Session:** [BOOK_TITLE / CHAPTER_NUMBER / SCENE_NUMBER]

| Parameter | Your Entry |
|---|---|
| **Character** | [E.G., Callum] |
| **Arc Stage** | [E.G., Book 3 — Defenses Cracking] |
| **Emotional State** | [E.G., Baseline Guarded / Vulnerability / Conflict] |
| **Scene Type** | [E.G., Dark Moment / First Kiss / Banter-Heavy Montage] |

### 7.3.2 The Four-Step Retrieval Process

1. **Identify** the four scene parameters (completed in the worksheet above).
2. **Navigate** to the correct folder: Character Voice Library → Series → Character → Arc Stage.
3. **Select** the correct file by matching the emotional state and scene type in the file name to your four parameters.
4. **Deploy:** Open the file. Copy the Dialogue Matrix into your AI tool's system prompt. Append the Emotional Filter. Append the genre-calibration settings. Add the Subtext Injection instruction for this specific scene. Hit generate.

### 7.3.3 Prompt Assembly Verification Checklist

Confirm every layer is in place before you hit generate.

- [ ] Layer 1: Dialogue Matrix pasted into the system prompt
- [ ] Layer 2: Three-Tier Emotional Filter appended
- [ ] Layer 3: Genre-calibration settings appended
- [ ] Layer 4: Subtext Injection instruction added for this specific scene (felt emotion and expressed emotion named)
- [ ] All four scene parameters from Step One match the file you opened
- [ ] Prompt is ready to generate
