## 7.6 Troubleshooting: Diagnosing Retrieval Friction

Use this decision tree when a Pull-and-Deploy test exceeds sixty seconds. The friction is always local. The fix is always small.

**Step 1 – Where did the navigation slow down?**

| Symptom | Diagnosis | Fix |
|---|---|---|
| I hesitated at a folder level, unsure which folder to click | The folder label is too vague | Rename it with a more specific descriptor |
| I opened the correct folder but hesitated between two or more files | The file names are too similar | Add a distinguishing tag to each name |
| I had to click through more than four levels to reach the file | The nesting is too deep | Flatten one level by combining two subfolders |
| I opened the wrong file and had to go back | The file name does not match the content | Rename the file to reflect what it actually contains |

**Step 2 – Apply the single fix. Re-test. Confirm the retrieval lands under sixty seconds.**

If the friction persists after one fix, check whether you applied a scene-type template without confirming it matches your genre calibration. The two layers stack. The genre calibration sets the range. The scene-type template modulates within it. Verify both are present and correctly ordered in your file, then re-test.
