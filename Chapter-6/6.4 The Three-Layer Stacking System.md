## 6.4 The Three-Layer Stacking System

Your complete emotional instruction set requires three layers operating simultaneously. Each layer governs a different dimension. All three must be present in every generation prompt.

| Layer | What It Governs | Source |
|---|---|---|
| **Layer 1: Character Filter** | Internal emotional logic (what the character feels, manages, and hides) | Chapter 5 Three-Tier Emotional Filter |
| **Layer 2: Genre Calibration** | Volume and density for your market (how loud, how thick, how fast) | Genre Calibration Reference Chart |
| **Layer 3: Scene Template** | Specific emotional signature of this moment in the story | Scene Type Emotional Template Library |

### 6.4.1 Three-Layer Stacking Verification Checklist

Run this before every generation pass.

- [ ] Layer 1: My character's Three-Tier Emotional Filter is included in the prompt.
- [ ] Layer 2: My genre calibration parameters (Intensity, Subtext Density, Pacing Curve) are included in the prompt.
- [ ] Layer 3: My scene-type template configuration is included in the prompt.
- [ ] I have confirmed the scene-type template is applied on top of the genre calibration, not replacing it.
- [ ] I can name the emotional signature this scene should produce in one sentence.
