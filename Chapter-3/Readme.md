# Chapter 3: Psychological Profiling — The Seven-Layer Character Excavation Workbook
*A practical workbook for applying the concepts from the chapter.*

## How to Use These Materials

This workbook converts the Seven-Layer Character Excavation method from Chapter 3 into a complete, ready-to-use profiling system. You will find seven structured worksheets (one per layer), a voice-relevance filter, a thirty-minute sprint plan with pacing guide, three AI stress-test prompts, and a troubleshooting prompt for when you get stuck. Work through the layers in order during a single thirty-minute session per character. You will need a blank document, a timer, and your intimate knowledge of the character you are profiling. By the end, you will hold a documented, voice-focused psychological profile ready for translation into a Dialogue Matrix in Chapter 4.
